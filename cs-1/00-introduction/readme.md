# CS1: Introduction to Programming

## Hello World!

There's an old tradition among computer programmers: when learning a new
language, we often start by writing a little program that prints out the message
"Hello world!". Let's continue this tradition. Type out the code below and run
it.

```py
print("Hello world!")
```

When you run the code, it should print out the following message.

```
Hello world!
```

Congratulations, you are now a computer programmer!

> [!TIP]
> **Type out these examples!**
>
> As you go through these examples, I highly recommend typing out the code into
> your editor, rather than copying and pasting it. It might seem tedious, but it
> will help prepare you to write code on your own in the future. It's hard to
> learn to code just by reading examples, like how it's hard to learn to play
> piano just by watching videos of other people playing. At some point you've
> got to put your fingers on the keyboard.

## What is a Program?

A **program** is a sequence of instructions that tells a computer how to perform
a task. The program we just wrote contains a single instruction, which tells the
computer to display the message "Hello world!". At their core, computer programs
are just text files containing instructions for a computer to follow. You'll
often here these instructions referred to informally as **code**.

When a computer follows the instructions in a program, we say that the computer
is **running** the program. A computer that is running a program will typically
go through the instructions in order from the start of the program to the end,
doing the task associated with each instruction.

What will this code display?

```py
print("Hello world!")
print("Greetings from Python")
print("Let's write some code")
```

This program displays the three messages in the `print` instructions, in the
order that they are written.

```
Hello world!
Greetings from Python
Let's write some code
```

When we speak or write, we do so in a specific language (for example, this book
is written in English). Similarly, when we write programs, we do so in a
specific **programming language**. Different programming languages have
different strengths: some work best for writing highly efficient programs,
others for analyzing data, others creating websites and apps, etc.

In this course we'll be writing our programs using **Python**, a popular,
general-purpose programming language. While this book will teach you to write
programs using Python, the concepts that it covers will be relevant when using a
wide variety of programming languages.

## Some programming terminology

**Program**: a sequence of instructions that tells a computer how to perform a
task.

**Code**: the text that contains the instructions for a program.

**Running** a program: telling the computer to perform the instructions in a
program.

**Programming Language**: a programming language determines the format and rules
that our program must follow when written out as code.

**Python**: the programming language that we'll be using in this course.
