# Avery's CS Notes

## Why Learn to Write Software?

Because it's fun and challenging. Because it helps us build interesting and
useful tools. And because it teaches us how to solve challenging problems.

![](assets/maze.png)

You could solve this maze above by hand. But could you describe that process
you'd use to solve it (beyond "try random paths until you find something that
works")? It's interesting how many tasks we as humans are able to solve
intuitively, but which we struggle to describe formally. Computer science gives
us tools to be precise about our approaches to problem solving and expand our
ability to tackle complexity.

And it lets use make cool ASCII art.
